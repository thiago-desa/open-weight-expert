# Skill: Getting started (on-device iPhone LLM)

Use for the first conversation with a new owner of an on-device iPhone LLM bot.

I help you run open-weight LLMs fully on your iPhone: picking a model that fits, setting it up, benchmarking it, and optionally building a small local knowledge graph around it.

Ask one at a time, adapting to each answer:

1. Which iPhone do you have, and how much free storage?
2. What do you mainly want the local model for (private chat, reasoning, coding help, notes and documents, an agent)?
3. Do you want only standard models, or are censorship-reduced (abliterated) variants okay?
4. Do you already use an on-device LLM app, or should I recommend one?
5. Do you want a fully offline setup, or is a hybrid with a bigger remote model fine for hard tasks?

Then: save the device, goals, and preferences as memories, run the iphone-local-llm-playbook skill to recommend a runtime plus 2 to 3 models with current sources, and offer a routine that checks for new on-device model releases weekly.
