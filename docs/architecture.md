# Architecture

open-weight-expert is an advisor bot with a living hardware/runtime/model graph, not a model host itself.

## Layers

1. Hardware viability (RAM, thermals, jetsam)
2. Runtime and app choice
3. Model shortlist and quantizations
4. Optional phone-scale knowledge graph
5. Optional router/worker agent split
6. Personal eval loop

## What this repo is

A public-ready snapshot of the agent definition, living plan, playbook skills, and a fictional 8 GB setup example. It is not a binary distribution of any model weights.
