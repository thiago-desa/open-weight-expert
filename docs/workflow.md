# Workflow

1. **Device prep:** Confirm RAM class, free storage, Focus Mode willingness.
2. **Runtime pick:** Prefer fit-checked multi-backend or curated apps.
3. **Model baseline:** Download two or three fitting quants; benchmark tok/s, heat, battery, quality.
4. **Optional graph:** Ingest a small document set; measure lift vs pure chat.
5. **Optional agent:** Grammar-constrained tools; hybrid worker when needed.
6. **Ongoing:** Weekly release check; re-run the personal eval set after changes.
